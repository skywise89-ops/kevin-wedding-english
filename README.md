# Kevin’s Wedding English v3

한국인 웨딩 포토그래퍼를 위한 정적 현장 영어 PWA. 촬영 중 빠른 검색, 촬영 전 표현 준비, 평소 짧은 회상 연습을 연결합니다. 로그인·서버·유료 API·외부 폰트 없이 동작합니다.

## 화면

- **홈**: 현장 바로가기, 미완료 레슨 이어하기, 3분 회상, 촬영 준비. 기존 진도·복습 레슨·학습 기록·기본 20레슨과 실전 보충 라이브러리는 접어서 열 수 있습니다.
- **현장**: 한국어·영어·구어체 별칭 검색, 상황 필터, 저장한 표현, 이름과 순서를 정할 수 있는 촬영 준비 모음(최대 24개). 표현 중복 표시를 없애고 듣기·영어 크게 보기·저장·촬영 준비를 명확히 구분합니다.
- **분위기 만들기**: 신랑신부·친구·가족을 위한 10개 상황, 25개의 말을 실제 촬영 순서로 펼쳐봅니다. 상황 전체를 촬영 준비에 한 번에 담고, 개별 문장을 듣거나 저장할 수 있습니다.
- **연습**: 5장 회상 또는 10장 복습, 저장·어려웠던 표현·촬영 준비 리허설, 5문제 퀴즈, 따라 말하기, 이어 듣기. “다시” 평가도 현재 세트에 무한 재추가하지 않습니다.
- **레슨**: 기존 4주 20레슨 + 실전 보충 5레슨, 1분 회상·8분 핵심·3분 출력 단계 링크. 핵심 표현·상황 예시·실전 대화·영어 미션을 별표로 저장해 현장 목록과 연습으로 연결합니다. 퀴즈는 답변 확인 뒤 정답 문장을 저장할 수 있습니다. 스크롤 위치·체크리스트·퀴즈 답변을 보존합니다.

5초 탐색과 3분·12분 학습은 설계 목표입니다. 실제 사용자 탐색 시간·학습 효과를 측정했다고 주장하지 않습니다.

## 실행과 빌드

미리보기에는 의존성 설치가 필요하지 않습니다.

```sh
python3 -m http.server 4173
```

`http://localhost:4173`을 엽니다. 생성 파일을 갱신할 때:

```sh
npm install
npm run build
npm test
npx playwright install chromium webkit
npm run test:browser
```

`sharp`는 SVG의 PNG·ICO 출력, `playwright`는 브라우저 검증에만 사용하는 개발 의존성입니다. 앱에는 런타임 패키지가 없습니다. 시스템 Chrome을 사용할 때 `KWE_CHROME_PATH`에 실행 파일 경로를 지정할 수 있습니다.

빌드는 레슨 HTML, 아이콘, 해시가 포함된 서비스 워커를 순서대로 생성합니다. 콘텐츠·코드를 수정한 뒤 항상 `npm run build`를 실행하세요. GitHub Pages는 `main` 브랜치의 저장소 루트에서 배포합니다. 공개 주소는 [Wedding English](https://skywise89-ops.github.io/kevin-wedding-english/)입니다.

## 콘텐츠 편집

`data/phrases.json`은 현장 표현의 안정적인 ID, 영어·한국어, 상황·카테고리, 별칭(`keywords`), 우선순위(`priority`), 사용 팁(`note`), 짧은 표현(`shortEn`), 부드러운 표현(`politeEn`)을 보관합니다. `data/lessons.json`은 레슨의 단일 소스입니다.

가족·단체 촬영은 기존 20레슨을 유지하고 ID 21의 실전 보충 레슨으로 추가했습니다. 홈의 **가족·단체 촬영 연습** 또는 라이브러리의 **실전 보충** 필터에서 엽니다. 기존 현장 표현 6개와 동일한 ID·저장 상태를 공유합니다. 상황 연습·대화·퀴즈·미션·완료 및 복습 일정도 기존 레슨과 같은 흐름을 사용합니다.

친구 그룹 촬영은 ID 22의 실전 보충 레슨입니다. 기존 친구 그룹 촬영 표현 8개를 제공합니다. **친구사진**, **그룹 농담**, **환호**, **앨범 커버**로 검색하거나 홈의 **친구들과 즐거운 그룹 사진**에서 연습합니다. 핵심 6표현, 4개 상황, 대화·퀴즈에서 간격 정리, 가벼운 농담 하나, 동작 하나, 반응 촬영을 연결합니다. 농담에 반응이 없으면 편하게 촬영하는 대안을 제공하며 기존 레슨·표현·저장 데이터는 유지합니다.

문장을 바꿔도 기존 ID를 바꾸지 마세요. `python3 tools/enrich.py`는 이미 일치하는 영어 표현의 해석·상황 팁을 레슨으로 동기화하며, 기존 현장 ID와 별칭을 재생성하지 않습니다. 이전 추출 파일은 필요하지 않습니다. ID는 사용자 진도·저장·촬영 준비의 연결 기준입니다.

신체 접촉은 사전 동의, 좌우는 피사체/촬영자 기준 구분, 관계·호칭은 사용자의 선호 확인을 우선합니다. 납품 일정은 예시 표현이며 실제 약속한 기간으로 바꿔 말해야 합니다. 전문 원어민 검수와 실제 촬영 현장 사용성 측정은 별도 확인 사항입니다.

## 개인 데이터와 복구

기존 키 `kwe_state_v2`를 유지하고 내부 모델을 v3으로 확장합니다. v2의 레슨·카드·복습일·즐겨찾기·음성·화면 설정·체크리스트를 유지하며, `kwe_progress_v1`의 완료 기록도 이전합니다.

- 진행 중인 회상 세션은 매 카드·정답 확인·난이도 선택마다 저장합니다.
- 레슨과 현장에 같은 문장이 있으면 기존 표현 ID와 저장 상태를 공유합니다. 현장 목록에 없는 예시 문장은 `sentences`에 영어·해석 또는 명시된 상황 힌트·출처를 보관하며, 일반 백업에 포함합니다. 저장·촬영 준비·복습 기록이 있는 문장을 현장 검색과 연습에 연결합니다. 기존 v2/v3 백업은 이 추가 항목 없이도 복원됩니다.
- 현장 검색·필터·스크롤은 이 탭의 sessionStorage에 보관합니다. 검색어를 서버나 URL query로 보내지 않습니다. 홈 바로가기의 URL fragment는 사용자가 링크를 공유하면 함께 보입니다.
- 가져오기는 1MB 제한, 버전·스키마·값 검증, 내용 미리보기, 사용자 확인 순서입니다.
- 복원·초기화 전 원본은 `kwe_state_v2:recovery`에 보관합니다.
- 이전 상태로 돌아가려면 설정의 **변경 전 데이터 내려받기**로 복구 파일을 받고, **백업 가져오기**에서 확인 후 복원하세요. 마지막 변경 전 사본 하나를 보관합니다.
- 손상되거나 미래 버전인 데이터를 발견하면 덮어쓰기를 차단합니다. 설정의 **저장된 원본 내려받기**를 사용하세요.
- 데이터는 서버에 동기화되지 않습니다. 브라우저 저장소 삭제·기기 이동 전 백업을 내보내세요. 로컬 개발 주소와 기존 공개 사이트의 저장소는 서로 다릅니다.

## 촬영 분위기를 만드는 말

홈 또는 현장의 **분위기 만들기 10가지**에서 오늘 쓸 상황을 고릅니다. 커플의 첫 느낌·평소 장난·귓속말·걷기, 친구들의 이야기·키스와 환호·앨범 커버 포즈, 가족의 감사·웃음 참기·촬영 사이의 편안한 대화까지 25개 문장을 추가했습니다. 현장 표현은 총 **162개**, 기존 14개 카테고리를 유지합니다.

**촬영 준비에 담기**는 이미 담긴 표현을 유지하고 빠진 문장만 순서대로 추가합니다. 남은 공간이 부족하면 상황 일부를 담지 않고 정리할 행동을 안내합니다. 모음은 기존 최대 24개입니다. **평소 장난**, **키스 환호**, **가족 감사**, **촬영 사이** 같은 한국어로 개별 표현을 검색할 수 있습니다.

보충 레슨 **23·24·25**에서 상황만 보고 첫 말을 떠올린 뒤 다음 안내를 이어 말합니다. 각 레슨의 핵심 6표현 외에도 시나리오와 대화에 해당 상황의 전체 순서를 제공합니다. 레슨·현장·분위기 만들기는 같은 문장 ID와 저장 상태를 공유합니다. 기존 137표현·22레슨 데이터, 사용자 진도·복습 일정·저장·음성 설정은 보존합니다.

## 오프라인과 업데이트

첫 준비가 완료되면 홈·현장·연습·기본 20레슨과 보충 레슨·데이터·아이콘 전체를 오프라인에서 사용할 수 있습니다. 준비 상태는 활성 서비스 워커의 실제 캐시 목록으로 확인합니다. 저장소 삭제나 캐시 제거 후에는 준비를 다시 확인하세요.

각 릴리스에 HTML·코드·데이터의 SHA-256 해시를 함께 생성합니다. 설치는 모든 파일의 해시 검증이 성공한 경우에 완료합니다. 실패한 캐시는 폐기하며 마지막 정상 버전을 유지합니다. 알려진 파일의 캐시가 사라진 경우에도 동일 해시의 파일만 복구합니다. 다른 앱의 캐시는 삭제하지 않습니다.

업데이트가 준비되면 **업데이트 적용**을 눌러 전체 릴리스를 전환합니다. 기존 온라인 페이지와 데이터가 서로 다른 버전으로 자동 갱신되지 않습니다.

iPhone Safari 공유 메뉴에서 **홈 화면에 추가**로 설치합니다. Web Speech 음성의 오프라인 가능 여부는 기기 음성 엔진에 달려 있습니다. 네트워크 음성은 연결이 필요할 수 있으며 음성 파일은 앱 캐시에 저장하지 않습니다. 화면 잠금·앱 전환 시 이어 듣기를 멈춥니다.

음성인식은 지원되는 환경에서만 사용합니다. 인식된 문장과 단어 일치는 발음 정확도 평가가 아닙니다. 권한 거부·미지원·오프라인에서도 직접 따라 말하고 다음 표현으로 진행할 수 있습니다.

## 아이콘과 디자인

둥근 말풍선 카메라를 채택했습니다. `docs/icon-comparison.html`에서 네이비·청록·밝은 바탕 3안을 비교할 수 있습니다. SVG 원본, 1024px 마스터, 180/192/512px PNG, 별도 maskable PNG, 16/32/48px ICO를 제공합니다. 원본은 불투명 정사각형이며 홈 화면 외곽 모서리는 OS가 처리합니다. 새로운 `-v3` 경로를 사용하며 기존 아이콘 URL도 유지합니다.
