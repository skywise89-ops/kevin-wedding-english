# Wedding English v3 시각 자산

기존 제품 이름과 카메라 정체성을 계승. 대상 저장소의 실제 UI와 아이콘을 기준으로 개편.

- 원본 로고: 기존 `assets/icon.svg`, 네이비 카메라. 신규 `assets/icon-v3.svg`는 둥근 카메라·말풍선 통합.
- 비교 시안: `docs/icons/option-a.svg`, `option-b.svg`, `option-c.svg`. 비교 화면 `docs/icon-comparison.html`.
- 색상: 종이 #f6f5f0, 밝은 패널 #fffefa, 잉크 #182d34, 행동 #16675b. 어두운 화면 #101e24.
- 서체: 기존 Apple 시스템 한글·영문 서체 계승. 오프라인 외부 폰트 의존 없음.
- 별도 실물 제품 사진과 브랜드 가이드 파일 없음. 실제 도구 UI에 불필요한 사진을 추가하지 않음.
- 대표 화면은 검증 시 `artifacts/`의 실제 브라우저 캡처로 보관. 기기 실측이 아닌 캡처는 에뮬레이션으로 명시.
