# 확인한 제품 사실

2026-10-02 KST. 원본 GitHub README와 HTML/CSS/JS·JSON을 직접 확인.

- 기존 앱: 20개 레슨, 129개 표현, 14개 카테고리. 정적 GitHub Pages PWA.
- 브라우저 SpeechSynthesis, 선택적 SpeechRecognition. 음성인식 결과는 단어 일치이며 실제 발음 평가는 아님.
- localStorage `kwe_state_v2`, 과거 `kwe_progress_v1`, JSON 백업.
- 사용자 요청: 현장 5초 탐색 목표, 촬영 전 3분 준비, 매일 12분 학습. 이는 검증할 목표이며 현재 성능 사실 아님.
- 아이폰은 아이콘 원본의 정사각형을 OS가 마스킹한다. 네이티브 layered 아이콘 체계를 PWA가 자동 지원한다고 가정하지 않음.
