# Wedding English v3 — 제품과 디자인

대상: skywise89-ops/kevin-wedding-english. 기존 로컬 Eng for Henry와 별도 checkout.

## 확인한 사실

README·실제 소스 기준 정적 HTML/CSS/JS, 20레슨, 129개 표현, 14개 카테고리. 기존 아이콘은 네이비 카메라, 서체는 Apple 시스템 서체. GitHub Pages 하위 경로에서 실행하며 서버·로그인·유료 API 없음.

## 가장 큰 문제 5개

1. `assets/field.js:match`는 통합 문자열의 부분 일치만 지원. 실제 검색 “턱 내려”, “좀 가까이”가 표현의 한국어 활용형과 달라 누락된다.
2. `render`가 즐겨찾기 영역과 전체 결과에 같은 표현을 중복 표시한다. 카드 전체 클릭도 음성 재생으로 이어져 스크롤·상세 탐색 중 오재생 위험이 있다.
3. `outdoor-btn`은 종료 시 테마를 auto, 크기를 16으로 덮어쓴다. 사용자 기존 선택을 잃는다.
4. 연습은 새로운 카드도 모두 복습 대상으로 집계하고 20개 무작위 추출, “다시” 평가 시 같은 세션에 계속 재추가한다. 미완료 세션도 저장하지 않는다.
5. `sw.js`는 캐시 설치 실패를 숨겨 활성화하고 데이터는 네트워크 우선, 코드는 캐시 우선으로 읽는다. 서로 다른 버전 혼합 및 준비 전 오프라인 보장 문구 문제가 있다.

## 화면 구조와 우선순위

- 홈: 촬영 현장 바로가기 / 이어서 12분 학습 / 3분 회상 / 접을 수 있는 기록과 20레슨.
- 현장: 검색 / 빠른 상황 / 전체·저장·촬영 준비 / 카테고리 / 한 번만 표시되는 표현 / 영어 크게 보기.
- 연습: 5장 짧은 복습 / 즐겨찾기 / 어려웠던 표현 / 촬영 준비 / 퀴즈·따라 말하기·듣기.
- 레슨: 회상·핵심·출력 단계 링크, 위치·체크·퀴즈 보존.

## 시각 체계

기존 네이비를 텍스트와 다크 배경에 계승. 밝은 배경 #f6f5f0, 패널 #fffefa, 강조 #16675b, 다크 배경 #101e24. Apple 시스템 서체 유지해 iPhone 한글 가독성과 오프라인 일관성 확보. 글자 크기 13/15/18/22/28/36, 간격 4/8/12/16/24/32. 현장 주요 버튼 48px, 카드 곡률 24px. 둥근 선 끝 SVG 아이콘, 160ms 상태 전환, reduced motion에서는 전환 제거.

## 아이콘 시안

A 네이비 말풍선 카메라: 기존 브랜드 연속성.
B 청록 말풍선 렌즈: 단일 실루엣, 작은 크기 식별성. 채택.
C 밝은 바탕 둥근 카메라: 친근한 인상, 밝은 홈 화면에서 대비 약함.

각 시안은 실제 앱 아이콘 크기, 밝고 어두운 홈 화면 배경에서 비교한다. 불투명 정사각형 원본, iOS 마스킹은 OS에 맡기며 Android maskable은 별도 안전 영역으로 제작한다.

## 검증 기준

실제 iPhone·VoiceOver 검증과 데스크톱 Chromium/WebKit 모바일 에뮬레이션을 구분한다. 5초 탐색은 제품 목표이며 실제 사용자 측정 전 성과로 주장하지 않는다. 기기 음성과 음성인식·백그라운드 재생 지원도 별도 확인 항목이다.
