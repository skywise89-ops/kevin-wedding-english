# Wedding English v3 검증 기록

검증일: 2026-10-02 KST. 대상 저장소 `skywise89-ops/kevin-wedding-english`, 작업 브랜치 `codex/wedding-english-v3`. 기존 Eng for Henry는 수정하지 않았다. 이 문서는 배포 전 검증 기록이다.

## 실행 결과

- `npm run build`: 20레슨·3개 아이콘 시안·아이콘 파생 크기·서비스 워커 생성 성공.
- 릴리스 `v3-be700f5fe259`: 오프라인 리소스 49개, 파일별 SHA-256 검증.
- `npm test`: 19개 단위 테스트 통과. 기존 데이터 이전, 검색, 복습 분량·순환, 미래/잘못된 백업 차단, 야외 설정 복원, 기존 ID·레슨 URL 검증.
- `npm run test:browser`: Chromium·WebKit 합계 121개 검증 통과. 정상 사용 흐름의 JavaScript 오류·실패한 리소스 요청 없음.
- 정적 HTML 24개, 로컬 링크·자산 참조 380개 확인. 모든 20레슨 포함.
- `git diff --check`: 통과.

브라우저 검증은 macOS의 headless 시스템 Chrome과 Playwright WebKit 26.5에서 수행했다. 모바일 viewport 390×844, DPR 2, 터치 입력, 320/375/430px 폭, 가로 844×390 및 데스크톱 1200×900을 확인했다. **실제 iPhone Safari 또는 iOS 시뮬레이터 검증이 아니다.**

## 요청한 사용 시나리오

| 시나리오 | 확인한 결과 | 검증 범위 |
|---|---|---|
| 처음 사용해 현장 모드 열기 | 첫 홈 화면의 ‘촬영 현장 열기’로 탐색 성공 | 두 브라우저 자동화. 신규 사용자 실측은 미실시 |
| ‘턱 내려’ 검색·확인·재생 | 적절한 표현이 첫 결과, 저장 후 중복 없음. 재생·중지·실패 상태 정상 | 실제 검색. 음성 이벤트는 테스트 대역으로 검증 |
| 촬영용 표현 모음 준비 | 표현 추가·이름·순서 변경 저장, 큰 영어 화면 정상 | 두 브라우저 |
| 준비 후 오프라인 사용 | 현장 검색·저장한 표현·촬영 준비·레슨·회상 정상 | 초기 캐시 준비 완료 후 네트워크 차단 |
| 3분 회상 중단·재개·완료 | 5장 세트, 정답 확인·평가 상태 보존. ‘다시’로 무한 증가하지 않음 | 두 브라우저. 실제 소요 시간 측정은 미실시 |
| 기존 사용자 데이터 | v2 레슨·카드·일정·저장·체크·음성 설정 유지. v1 완료 기록 이전 | 단위 테스트 및 브라우저 v2 주입 |
| 백업 오류와 복구 | 잘못된 형식·1MB 초과 거절. 확인 전 교체 없음. 변경 전 원본 내려받기·재가져오기 성공 | 두 브라우저 |
| 서비스 워커 업데이트 | 대기 중 기존 릴리스 유지, 사용자 적용 후 일괄 전환. 설치 실패·해시 불일치 시 마지막 정상 릴리스 보존 | Chromium. 다른 앱 캐시 보존 확인 |
| 화면 크기·접근성 기본 | 가로 넘침 없음, 표시된 활성 버튼 48px 이상, 아이콘 이름, 카테고리 선택 후 키보드 초점, 큰 문장 닫기 | 두 브라우저. VoiceOver 읽기 순서는 미확인 |
| 라이트·다크·야외 | 테마 전환·26px 현장 글자·야외 종료 후 이전 설정 복원, 브라우저 theme-color 일치 | 두 브라우저. 실제 야외 조도 미측정 |

Chromium은 `browserContext.setOffline(true)`로 차단했다. WebKit은 해당 설정에서 문서 이동이 실패하는 [Playwright 이슈 #42775](https://github.com/microsoft/playwright/issues/42775)와 같은 오류가 발생했다. WebKit 검증에서는 원본 HTTP 서버를 실제로 중지한 뒤 캐시로 화면을 이동했다. 네트워크 복구 후 서버를 같은 포트에서 재개했다.

## 색상과 화면 검수

WCAG 상대 휘도 공식으로 핵심 색상 조합을 계산했다. 전체 화면 접근성 인증을 의미하지 않는다.

| 모드 | 본문 / 배경 | 보조 텍스트 / 카드 | 주요 버튼의 글자 / 배경 |
|---|---:|---:|---:|
| 라이트 | 13.14:1 | 5.81:1 | 6.72:1 |
| 다크 | 15.39:1 | 8.36:1 | 7.67:1 |
| 야외 | 19.03:1 | 13.20:1 | 9.87:1 |

실제 브라우저 캡처를 확인해 검색·지우기 버튼 겹침을 수정했다. 아이콘 A/B/C는 60px·36px, 밝고 어두운 배경에서 비교했다. B는 하나의 둥근 카메라·말풍선 실루엣과 대비가 가장 명확해 채택했다. 180/192/512/1024px PNG는 불투명 정사각형으로 검증했다. 별도 maskable 아이콘도 생성했다.

캡처와 원시 결과는 로컬 `artifacts/`에 있다.

- `screens-overview.png`: 홈·현장·3분 회상.
- `icons-chromium.png`: 아이콘 3안 비교.
- `show-*.png`, `outdoor-*.png`, `dark-*.png`, `small-*.png`: 큰 문장·야외·다크·작은 폭.
- `browser-results.json`: 각 검증 이름과 환경 기록.

## 실제 iPhone에서 남은 확인

다음 항목은 기기 미접속으로 확인하지 못했다. 브라우저 에뮬레이션 결과와 구분해 배포 전 실기기에서 확인해야 한다.

1. Safari와 홈 화면 설치 상태 각각에서 하단 탭·노치·safe area·가로 방향 확인.
2. 검색 키보드 열기·닫기, 스크롤·상황 필터 이동 후 위치 복원 확인. 코드에는 visualViewport 대응과 safe-area inset을 적용했다.
3. VoiceOver로 탐색·상황 검색·즐겨찾기·설정 대화상자·영어 크게 보기 조작. 시스템 큰 글자와 확대 200% 확인.
4. 실제 영어 음성 재생·중지·실패·선택한 음성 유지 확인. 비행기 모드에서 기기 음성이 재생되는지 별도 확인. 앱은 음성 파일을 캐시하지 않는다.
5. 음성인식 허용·거절·미지원 상태 확인. 인식 문장은 발음 점수로 표시하지 않으며 직접 따라 말하기로 진행한다.
6. 화면 잠금·앱 전환 시 이어 듣기 중지, 장기간 미사용 후 캐시 준비 상태 확인.
7. 웨딩 포토그래퍼의 한 손 조작·실제 5초 탐색·3분 준비·12분 학습과 표현 회상 효과 측정. 자연스러운 영어는 전문 원어민의 현장 맥락 검수 추가 권장.

## 배포 준비

정적 배포 묶음 `artifacts/wedding-english-v3.zip`의 루트에 앱 파일을 배치했다. GitHub Pages의 기존 `/kevin-wedding-english/` 경로에 같은 폴더 구조로 배포하면 기존 origin·localStorage를 유지한다. 테스트에서는 `/wedding/` 하위 경로로 동일한 상대 URL 처리를 검증했다.

이번 작업의 로컬 미리보기 주소는 기존 공개 사이트와 저장소가 다르므로 공개 사이트의 사용자 진도가 자동으로 보이지 않는다. 실제 기기의 데이터 복사본으로 업데이트 이전을 최종 확인한다. 공개 주소는 [Wedding English](https://skywise89-ops.github.io/kevin-wedding-english/)이다. `main` 브랜치의 저장소 루트가 Pages 배포 대상이다.
